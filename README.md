# استودیوی پارس‌پادکست (ParsPodcast Studio)
### استودیوی بومی تولید خبر و پادکست هوشمند آفلاین با هوش مصنوعی بومی

**ParsPodcast Studio** یک نرم‌افزار حرفه‌ای، بومی و پیشرفته برای سیستم‌عامل اندروید ۱۵ است که زنجیره کامل فرآیند تولید پادکست از جمع‌آوری اخبار، تدوین متن و فیلمنامه پادکست با مدل زبانی محلی Gemma 4 E4B، گویندگی و سنتز گفتار با مدل مانا (Sherpa-ONNX)، میکس و مهندسی چندترکه صدا، تولید فید استاندارد RSS 2.0 و انتشار در سرورهای خودمیزبان را بدون نیاز به اینترنت فراهم می‌آورد.

---

## قابلیت‌های کلیدی

1. **زبان مادری و تقویم خورشیدی:**
   - پشتیبانی ۱۰۰٪ زبان فارسی با چیدمان راست‌به‌چپ (RTL) در تمامی صفحات Jetpack Compose.
   - گاه‌شماری خورشیدی (جلالی) بومی برای نام‌گذاری، آرشیو و تاریخ‌نگاری اپیزودها.
   - تبدیل دقیق اعداد انگلیسی/عربی به حروف فارسی جهت خوانش بدون سکته در موتور سنتز گفتار.

2. **پردازش محلی با هوش مصنوعی (LiteRT-LM):**
   - اجرای کامل مدل زبانی Gemma 4 E4B به صورت On-Device با پشتیبانی از شتاب‌دهنده سخت‌افزاری GPU (Vulkan) و Fallback پایدار به CPU (XNNPACK).
   - ساخت سناریوی پادکست تک‌مجری یا دومجری در فرمت ساخت‌یافته JSON با خطایابی و بازیابی خودکار.

3. **سنتز گفتار آفلاین فارسی (Sherpa-ONNX):**
   - استفاده از مدل عصبی باکیفیت Mana Persian Piper بدون اتصال به اینترنت.
   - قطعه‌بندی هوشمند جملات طولانی و فرار از کرش‌های حافظه با کش صوتی ۱۶ بیتی WAV.

4. **استودیوی چندترکه صدا (Multitrack Audio Studio):**
   - پشتیبانی از ۶ لاین صوتی همزمان (اینترو، گوینده اصلی، کارشناس، موسیقی پس‌زمینه، افکت و اوترو).
   - داکینگ خودکار موسیقی (Auto-Ducking) هنگام سخن گفتن گویندگان.
   - لیمیتر نرم بر پایه تابع هذلولوی (`tanh`) برای جلوگیری قطعی از دیستورشن و اعوجاج.
   - پن استریو با قانون توان ثابت (`Constant Power Panning`).
   - پخش چندترکه بدون لکنت و همگام با Media3 ExoPlayer.

5. **توزیع و فید استاندارد RSS 2.0:**
   - تولید فایل `podcast.xml` مطابق ضوابط رسمی Apple Podcasts و Spotify با تگ‌های اختصاصی آی‌تونز.
   - شناسه‌های یکتای پایدار (Stable GUID) که با تغییر هاست از بین نمی‌روند.
   - موتور اعتبارسنجی داخلی (Validator) برای بررسی پیش از انتشار.
   - بسته‌بندی صادرات آفلاین همراه با راهنمای جامع فارسی.
   - بارگذاری امن با WebDAV over HTTPS با رمزنگاری گذرواژه‌ها در سخت‌افزار Android Keystore.

## دستگاه هدف مرجع
- **مدل دستگاه:** Daria Band (داریا باند)
- **پردازنده:** MediaTek Dimensity 7050
- **پردازنده گرافیکی:** Mali-G68 MC4
- **حافظه رم:** ۸ گیگابایت
- **سیستم‌عامل:** اندروید ۱۵ (API 35)

---

## معماری و پوشه‌بندی پروژه

```
├── android/                         # سورس‌کد بومی اپلیکیشن اندروید
│   ├── app/src/main/
│   │   ├── java/com/parspodcast/studio/
│   │   │   ├── data/               # دیتابیس Room، انکودرها، هاستینگ و ریپازیتوری‌ها
│   │   │   ├── domain/             # منطق خالص تجاری، تقویم جلالی، تولید و اعتبارسنجی فید
│   │   │   ├── service/            # سرویس پیش‌زمینه صوتی Media3
│   │   │   └── ui/                 # کامپوننت‌ها و اسکرین‌های Jetpack Compose (RTL)
│   │   └── res/                    # رنگ‌ها، تم‌ها و فونت‌های استاندارد
│   └── app/src/test/               # آزمون‌های واحد و یکپارچگی سرتاسری
├── src/                             # پروتوتایپ و مرجع وب (React + Vite + Tailwind CSS)
└── docs/                            # مستندات فنی و گزارش‌های ممیزی فازهای ۱ تا ۱۰
```
